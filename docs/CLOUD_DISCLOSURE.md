# VoicePilot｜Geminiへの画面情報送信（P0-3、v0.23.21）

VoicePilotは通常はローカルのOllamaを選択できます。Geminiを有効にした場合、音声指示・画面メタデータを外部APIに送信することがあります。以下の確認は、**画面の生本文やスクリーンショット**という追加の開示に対するものです。

## 1. 画面説明

- **Geminiで、Chromeの表示本文を読み込む場合**は、現在の1回の送信についてローカルGUIの確認が必要です。
- **Geminiで画面画像を送る場合**は、設定の画像送信許可に加え、現在の1回の送信についてローカルGUIの確認が必要です。
- 確認を拒否した場合・確認手段がない場合は、本文の読取・画像撮影・モデルへの送信を始めずに停止します。
- 確認中に対象ウィンドウが変わった場合も停止します。送信直前に通常GUIの5分間許可と停止状態を再確認します。
- ローカルのOllamaにはこの追加のクラウド確認は不要です。画面説明の回答全文は操作ログに複写しません。

## 2. AIが画像観測を提案した場合

- モデルの `screen_observe` 提案だけでGeminiへの画像送信を承認したことにはしません。
- **各画像**について、ユーザーが操作するGUI確認を行います。拒否・停止・許可期限切れ・対象変更の場合は送信しません。
- 撮影後、モデル呼出しの直前に対象ウィンドウと保護対象プロセスを再確認します。古い画像は破棄します。

## 3. この仕組みで防げないこと

- 画面はモニターからキャプチャするため、画像に別のアプリ、通知、ポップアップやパスワードが写り込む可能性があります。許可前に画面を確認し、機密情報を閉じてください。
- **表示内容の自動秘密値検出、マスク処理、秘匿性の保証ではありません。** 送信前の最後の判断はユーザーによる確認に依存します。
- 他のタブや他のウィンドウのタイトル一覧は、タブ切替・ウィンドウ切替を指示した場合でもGeminiには送信しません。現在の画面のタイトル・要素名は依然として送られる場合があります。
- 画面本文のメタデータ、タイトル、操作命令など、従来の「Geminiに指示・画面の要素名・ウィンドウ名を送ることを許可」の範囲も機密情報を含む可能性があります.
- ウィンドウIDが変わらないままページ内容が変わること、確認と送信の間の短い競合、モデルへの送信後の取り消し不可などは残ります。
- クラウド側に転送されたデータを取り消すことはできません。機密情報のある画面はOllamaのローカルモードを推奨します。
