# VoicePilot｜初回の安全な試用手順（v0.23.15）

**現状：マイクとローカル音声認識を試すための限定モードは利用可能。Windows全体の操作を安心して任せられる正式運用には未達成。**

## 最初に理解しておくこと

- 通常のVoicePilotにはWindowsやChromeを操作する機能がありますが、**「安全な音声試用」では起動しません**。
- ZIPは開発者本人による独立した電子署名が未設定の試作版です。GitHubで公開されたZIP・CIの成功だけでは真正性を独立証明できません。出所を確認し、Windowsのセキュリティ警告を無理に解除して実行しないでください。
- 音声試用は、**アプリを操作せず、日本語で話した内容を画面に表示するだけ**。ファイルの読み取り、削除、OS操作、Chromeの操作、クラウドへの音声送信、更新適用、起動時のマイク録音を行いません。
- Windows 11の通常権限とPython 3.11が必要です。管理者として実行しないでください。
- 初回の仮想環境は解凍先に作られます。ライブラリがなければ、`INSTALL`と入力したときだけ**PyPIから**無料の音声認識ライブラリを取得します。これらはサードパーティのプログラムです。
- Whisperの音声モデル重みがPCになければ、画面のチェックボックスを明示して許可した場合にだけモデル配布元から取得します。初回ダウンロードでは通信とディスク使用量が発生しますが、**マイク音声そのものは送信しません**。
- 録音は明示的に「録音を開始」を押したときだけ。最大8秒で自動終了します。認識結果はアプリ内で表示するだけで、VoicePilotから保存しません。

## 試用する方法

1. [VoicePilot v0.23.15 のZIPリリース](https://github.com/ryotkkr-del/VoicePilot/releases)を入手して、新規の専用フォルダへ解凍します。大事なデータのあるフォルダを使わないでください。
2. フォルダ内の`try_voicepilot.bat`をダブルクリックします。**`setup_and_run.bat`ではありません。**
3. Python 3.11を使って仮想環境を準備します。追加パッケージのインストールが必要なら、説明を確認したうえで明示的に`INSTALL`と入力してください。拒否すればインストールせず終了します。
4. 小さな「安全なマイク試用」画面が開いたら「録音を開始」を押し、「音声のテストです」などの架空のフレーズを話します。
5. モデルがまだない場合は、モデルの初回ダウンロードを許可するか選んでください。個人情報や機密を含む発話は試用しないでください。
6. 「停止」を押すか最大8秒経過すると、**ローカルだけで**文字起こしします。「停止」を認識中に押した場合、計算そのものは瞬時には止められませんが結果は破棄します。
7. 文字起こしが成功しても**音声によるPC操作は実行されません**。実機の操作・停止の安全性は別検収項目です。

## ほかの安全診断

Python 3.11とライブラリが揃っていれば、以下も個別に実行できます。

```powershell
.\.venv\Scripts\python.exe -m app.p0_acceptance
.\.venv\Scripts\python.exe tests\windows_safety_check.py
```

`app.p0_acceptance`は本体・Chromeの版や署名鍵の有無などを読み取り専用で確認します。`tests\windows_safety_check.py`は隔離したダミーのテスト用ファイルのみ扱います。手動のメモ帳試験・マイクベンチマークについては[実機検収手順](P0_HARDWARE_ACCEPTANCE.md)を参照してください。

## 現在は避けること

- 個人ファイル、メール、ブラウザのログイン画面、金融情報、パスワードなどを音声操作させる
- 複数アプリにまたがる無人作業や自律タスクを普段使いPC上で実行する
- 署名なしの公開ZIPを正式な署名済み更新として扱う
- 実機で停止・対象切替・更新復旧が検証されていないのに「本番で安全」と判定する

まず**音声が拾えるか、文字起こしの誤認識がどの程度か**を確認し、実機P0検収が済んだ項目だけ段階的に試用範囲を増やします。
