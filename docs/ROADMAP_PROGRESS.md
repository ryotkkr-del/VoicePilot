# VoicePilot｜正式運用ロードマップ 進捗管理

**優先順位・合格条件の基準:** ユーザー提供「VoicePilot｜正式運用に向けた開発指示書」（2026-11-15）。このファイルはその指示書を上書きせず、GitHubの現行実装に即した**継続的な進捗表**として利用します。

**製品の固定目標:** Windows 11の普段使いPCで無料・高自由度の音声操作を継続利用し、可能な範囲でPC全体を扱う。既存のコード・履歴・GitHubリポジトリを維持する。安全検証のために管理者権限、汎用シェル、レジストリ編集、無許可のクラウド送信を解禁しない。

**判定:** `一部実装`は「合格」ではありません。`CIのみ検証`は実機合格を意味しません。各バージョンでこの文書と回帰テストを更新します。

## 優先順の次の実装

v0.23.20のP0-2改善は、通常文章入力の中断とロック失効をネイティブ入力境界まで伝えるものです。Windows実機の停止確認、Chrome拡張機能への送信後の取り消し可能性、独立署名付き更新は未検証・未達成です。


1. **P0-1〜P0-3:** v0.23.19で[通常GUIの初期ロック](DEFAULT_LOCKED_CONTROL.md)を追加。次はロック解除後の各操作経路の実機停止、画像送信・画面上の機密、入力途中のフォーカス変更を検証する。
2. **P0-4:** [オフライン鍵・署名準備](OWNER_SIGNED_RELEASE.md)と[別フォルダへの署名済み移行](OFFLINE_SIGNED_MIGRATION.md)のコードを用意。次は開発者本人による本物の鍵の安全な作成と独立した指紋公表、**未公開バージョンの署名済み公式Releaseの発行**、通常権限Windows実機での移行・復旧を行う。
3. **P0-5:** v0.23.18で[任意メモ帳実機試験](P0_HARDWARE_ACCEPTANCE.md)に各文字直前のEsc停止・20秒制限を追加。次はユーザー所有Windows 11通常権限で**本人の同意のもと**安全試用→ダミーメモ帳のフォーカス切替・Esc停止→Chromeの順に検証し、結果と問題を反映する。
