# VoicePilot｜正式運用ロードマップ 進捗管理

**優先順位・合格条件の基準:** ユーザー提供「VoicePilot｜正式運用に向けた開発指示書」（2026-11-15）。このファイルはその指示書を上書きせず、GitHubの現行実装に即した**継続的な進捗表**として利用します。

**製品の固定目標:** Windows 11の普段使いPCで無料・高自由度の音声操作を継続利用し、可能な範囲でPC全体を扱う。既存のコード・履歴・GitHubリポジトリを維持する。安全検証のために管理者権限、汎用シェル、レジストリ編集、無許可のクラウド送信を解禁しない。

**判定:** `一部実装`は「合格」ではありません。`CIのみ検証`は実機合格を意味しません。各バージョンでこの文書と回帰テストを更新します。

## 優先順の次の実装

1. **P0-1〜P0-3:** ダミー情報を用いたWindows/Chrome画面・AIプロンプト・ログ・停止競合の追加回帰テスト。拒否・未確認時は安全停止する。
2. **P0-4:** 既存更新の単体テストを拡充し、開発者が管理する独立署名鍵の仕組みを設計する。鍵をリポジトリやGitHub Releaseに公開しない。真正性の検証なしに「署名済み」とは呼ばない。
3. **P0-5:** 通常権限で実行する実機向け試験手順、結果記録フォーマットを準備し、ユーザー環境での結果を確認する。

## 現在のリリース判定（v0.23.6での目標）

- [ ] P0-1〜P0-3の全危険経路テストに合格（既存CIだけでは不足）
- [ ] 更新元の独立した真正性検証を実装
- [ ] 失敗復旧・ロールバック・設定保持を繰り返し確認
- [ ] Windows実機で音声・Chrome・GUI操作・停止を確認
- [ ] 実機の品質・性能を測定し閾値達成
- [ ] 長時間利用・障害・スリープ・通信断に合格
- [ ] 重要データの無人操作を避ける範囲・残余リスクを明示

**正式運用の判定は引き続き保留。** CIが成功しても実機で安全と断定しません。

## 各更新時の報告ルール

バージョン・mainコミット／今回のリスクと変更ファイル／Windows CI結果／**Windows実機の検証状況**／更新とユーザーデータへの影響／未解決の重大リスク／次の優先3項目、を記載します。
